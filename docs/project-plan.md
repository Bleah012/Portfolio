# Project Plan

## Goal

Build a personal portfolio website inspired by the reference design, with an admin panel for adding, editing, and deleting content without changing code.

## Main Sections

- Hero
- About
- Skills
- Projects
- Experience
- Certifications
- Blog
- Testimonials
- Contact
- Footer

## CRUD Content

The admin panel should allow updates for:

- Profile information
- Projects
- Skills
- Experience
- Certifications
- Blog posts
- Testimonials
- Social links
- Contact details
- Resume/CV link
