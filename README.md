# Personal Portfolio

A personal portfolio website with a frontend website and a backend CMS/admin panel for CRUD content updates.

## Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend/CMS: Sanity
- Version Control: Git and GitHub
- Hosting: Vercel and Sanity free tiers
